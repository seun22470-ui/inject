# Inject Terminal Agent

Autonomous PowerShell terminal agent with native skills:
- Live DuckDuckGo Web Search (zero API keys needed)
- Website Stack Inspection (Next.js, React, Tailwind, Supabase, Stripe detection)
- Webpage Content Extraction (headings, text, metadata, tables)
- Native Package Installation (`npm install`, `pip install`)
- Real PowerShell & Shell Command Execution
- Live Code Generation and Execution

## Installation (Windows PowerShell)

Install globally from your GitHub repo:
```powershell
npm install -g git+https://github.com/seun22470-ui/inject.git
```

## Running the Agent

Start the agent in any PowerShell terminal:
```powershell
inject-agent
```
(or `forge`)

Type `/help` inside the agent to see all active skills and commands.
